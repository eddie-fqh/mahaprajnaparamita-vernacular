# 《大般若波罗蜜多经》第 398 卷 · 白话解读

有一个人，把自己卖了，割开胳膊放血，敲碎骨头取髓，准备剖开胸口把心掏出来，只为买一个听法的机会。这个人叫常啼菩萨。

我们这个时代，知识唾手可得。打开手机，搜索引擎，短视频，什么都有。我们对知识的态度变成了，免费的最好，太长不看。有人为了一个课程犹豫要不要花九块九。

《大般若经》第三百九十八卷，讲了一个用血和骨头买法的人。他的故事，也许会让你重新想想，什么东西值得你用生命去换。

上一卷讲了平等法性与一切皆化的深义。这一卷，佛陀突然换了风格，他开始讲一个故事。常啼菩萨的故事。

常啼菩萨本来住在阿练若处，就是荒野。有一天他突然听到空中有声音对他说，往东走，你一定能听到甚深般若波罗蜜多。但条件是，不要怕疲倦，不要想睡觉，不要想吃喝，不要怕冷热，心不要散乱，不要左顾右盼。

然后空中的声音说了一句极其深刻的话。勿动于色，勿动受想行识。对一切法都不要动摇。为什么。若于诸法有所动者，则于佛法不能安住。

你对任何一法执著了，你就站不稳了。你执著于禅定的喜悦，你就被禅定绑住了。你执著于般若的深奥，你就被般若绑住了。真正的求法者，是在一切法中不动摇的人。不是什么都不做，而是做一切事而不被任何一事抓住。

常啼菩萨听完，就往东走了。走了一阵他忽然想起来，我忘了问那个声音，到底要走多远，去哪个城市，找谁听法。他停下来，难过得捶胸大哭。

佛陀用了一个比喻。就像一对父母只有一个儿子，聪明英俊，万般疼爱。儿子突然死了。父母那时候的心里，只剩下一个念头，就是我的孩子。常啼菩萨也是如此，他心里只有一个念头，我什么时候才能听到般若波罗蜜多。

这份求法之心有多猛烈。就像中了毒箭的人，满脑子只想着什么时候能拔掉这支箭。不是闲情逸致，不是锦上添花。是命悬一线时的孤注一掷。

然后奇迹出现了。在他悲泣的那个地方，十方无量诸佛的影像出现在他面前。诸佛告诉他，从这里往东走五百逾缮那，有一座妙香城，城里有一位法涌菩萨，他会为你讲说甚深般若波罗蜜多。

诸佛还对他说了一段话。我们过去修菩萨行的时候，也像你现在这样用勤苦行求法。我们那时候也得到了像你现在证得的这些三摩地。我们是怎么从三摩地走向成佛的呢。我们对诸法无所执著。就这样，无所执著，就是般若波罗蜜多。

不是某个深奥的法门。不是某种特殊的技术。就是对一切法不执著。这就够了。

十方诸佛消失后，常啼菩萨做了一个决定。他要去见法涌菩萨。但他一穷二白，没有花香璎珞，没有金银珍宝，拿什么供养。他不能空手去。

于是他走进一座大城，站在集市上高声喊道，我今自卖，谁欲买人。我今自卖，谁欲买人。

没有人理他。因为恶魔把他的声音遮蔽了，让全城的人都听不到。

魔为什么要阻止他。因为魔知道，如果常啼见到了法涌菩萨，听到了般若波罗蜜多，他的智慧就像大海一样不可摧毁。然后他会度化无量众生，让魔的领地越来越空。

卖了很久没人买。他站在那里哭，说我有什么罪，只是想供养佛法，连卖身都卖不出去。

这时候天帝释化作一个年轻的婆罗门来试探他。说我不要人身，但我祭天需要人血，人髓，人心，你卖不卖。

常啼菩萨一听，高兴坏了。他二话不说，拿起刀刺自己的左臂放出血来，割开右腿取出骨髓，然后走到墙边准备剖开胸口挖心。

就在这时，一个长者的女儿从高楼上看到了这一幕。她跑下来问他为什么要这样做。常啼菩萨说，我为了供养甚深般若波罗蜜多和说法师法涌菩萨。

长者女听他讲完将要获得的功德，佛的金色身，三十二相，八十随好，十力四无畏，一切智，一切相智。她被震撼了。她说，为了获得这样的一种功德，就算舍弃恒河沙那么多的身命也应该。何况只是一条命。你别再伤害自己了，你需要多少供养的财物，我全部给你。我自己也要跟你一起去。

这个故事讲到这里，你有没有觉得自己的心被什么东西碰了一下。

也许你不需要割肉卖血。但也许你可以问问自己，有没有什么东西，值得你用最真诚的部分去换。不是钱，不是时间，是你内心最柔软的那个地方。
