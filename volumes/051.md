# 《大般若波罗蜜多经》第 51 卷 · 白话解读

你每天都在用的那个东西，眼睛，耳朵，鼻子，舌头，身体，意识，它们本身，是空的。不是坏了，不是没了，而是从来就不是你以为的那个样子。

哈喽，大家好，我是付启航 Eddie，欢迎回到我们的佛经解读系列。

有没有这样的经历。你站在一个十字路口，左边是你想要的，右边是你应该做的，前方是别人期待你去的方向，身后是你已经走过的路。四面八方，全是牵扯。你觉得自己被绑住了，动弹不得。

然后有人告诉你，那些绳子，根本不存在。

《大般若经》第五十一卷，就是来解开这些不存在的绳子的。

上一卷，善现讲了一切法无缚无解，没有束缚，也没有解脱，因为那个困住你的监狱，从来就没有真实存在过。这一卷，满慈子追问善现，你说的这些无缚无解的东西，到底是什么样的。

善现用了九个比喻来回答。如幻，如梦，如影像，如回响，如光影，如空中花，如阳焰，如海市蜃楼，如魔术变化。

九个比喻，说的是同一件事。你看到的，听到的，感受到的，想到的，全部都像幻术师变出来的道具。在舞台上栩栩如生，但你走到幕后，什么都抓不住。

不是说它们不存在，而是说它们的存在方式，和你以为的不一样。就像你在山谷里喊一声，回声清清楚楚地传回来，但那个声音在哪里。你去找，找不到一个实体。回声是真实的体验，却没有一个可以被抓住的本质。

善现接着说，不仅现在的感受是这样，过去的未来的也是。不仅好的感受是这样，坏的也是。不仅有染污的是这样，清净的也是。不仅世间法是这样，出世间法也是。

全部，无一例外，无缚无解。

很多人听到世间法是空的，心里想，那我去修出世间法，那个总是实在的吧。善现说，出世间法也一样。就像你做了一场噩梦醒来，以为踏上了实地，但脚下的实地，也是梦的一部分。

那怎么办。

答案是，以无所得而为方便。不是什么都不做，而是做的时候不抓。行动，但不执取结果。修行，但不执取成就。就像风吹过树林，树叶沙沙作响，风不会停下来说，你看我刚才吹动了那片叶子。风只是吹，自然而然。

讲完无缚无解，这一卷出现了重大转折。善现问佛陀一个根本问题，世尊，大乘到底长什么样。菩萨从哪里出发。大乘从哪里来，到哪里去。

佛陀的回答极其清晰。大乘的样貌，就是六波罗蜜多，布施，持戒，安忍，精进，禅定，智慧。但这六个不是六条规矩，不是任务清单。佛陀给每一个都加了同一句前缀，发应一切智智心，大悲为上首，以无所得而为方便。

先发心，发的是通向一切智慧的心。然后以大悲为引领，不是为了自己，是为了所有众生。最后以无所得为方法，做了，但不抓。

布施，不是我给了你多少，而是把一切都拿出来，同时不觉得自己给了什么。持戒，不是我忍住了多少欲望，而是自然地行走在善道上。安忍，不是咬牙扛住委屈，而是委屈在智慧的光里变得透明。禅定，不是入了多深的定境，而是能自在地出入，不被定境的美好留住。智慧，不是看透了多少道理，而是如实观察一切法的本性，同时不做任何执著。

每一个都回到同一个核心，做了，但不抓。像水流过石头，不留痕迹。

然后佛陀展开了大乘的第二个面向，二十种空。从内空到外空，从有为空到无为空，从毕竟空到无性自性空。二十个角度，让你看到同一个事实，一切法的本性，非常非坏，本性尔故。

什么意思。不是永恒不变的，也不是被谁破坏了才空的，而是它本来就是这个样子。空不是损失，是本然。就像天空不是因为没有云才空旷，天空本身就是空旷的。云来了，天空还是天空。云走了，天空也还是天空。空，是天空的本性，不是缺陷。

回到开头那个十字路口。你觉得被绑住了，左右为难。

但如果你能看到，那些让你为难的选项，本性都是空的。不是说它们不重要，而是它们没有你以为的那种固定的力量来捆绑你。你之所以觉得被绑住，是因为给每个选项贴上了太重的标签。

把标签轻轻揭下来。路还是那些路，但你的脚，自由了。
