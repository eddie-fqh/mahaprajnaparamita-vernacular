# 《大般若波罗蜜多经》白话解读

**528 卷现代白话解读 · Modern Chinese vernacular commentary on the Mahāprajñāpāramitā Sūtra**

玄奘译《大般若波罗蜜多经》共 600 卷，是汉传佛教篇幅最大的一部经，也是读的人最少的一部经。
原因很简单：它太长、太重复、文言太密。绝大多数人翻开第一卷就放下了。

这个仓库是一次很笨的尝试——**一卷一卷，用今天的话把它讲一遍。**

目前完成 **528 卷 / 600 卷**，约 **84 万字**。

## 这是什么，不是什么

**是**：逐卷的白话解读稿。保留原经的义理骨架和推进顺序，用现代口语、现代比喻讲出来。
每一卷可以独立读，也可以顺着读。

**不是**：不是逐字直译，不是学术译本，不是原文替代品。
遇到义理关口，我会停下来打比方、举例子——这些比喻是我加的，不是经文里的。

**读法建议**：把它当成入门的脚手架。真正想深入，请回到玄奘原译。
这份稿子的作用是让你有能力读下去，而不是替你读。

## 关于文本

这些稿子最初是为语音讲解写的口播稿，所以：

- 语气是讲给人听的，不是写给人看的
- 每卷结尾有一句固定的收束语
- 原始文件里「般若」被写成「波惹」（为了让语音合成读对 *prajñā* 的音）——
  本仓库已全部还原为「般若」，共 4,309 处

如果你发现义理讲错了、比喻不当、或者哪一卷读不通，
欢迎开 issue。**指出错误是对这件事最大的帮助。**
